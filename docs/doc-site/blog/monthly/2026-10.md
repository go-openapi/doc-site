October was a quiet maintenance month. The work ran to **13 load-bearing commits across
17 active repositories** (excluding bot and release-automation authors), most of it
dependency and security updates: a `golang.org/x/net` bump in **runtime** and **validate**,
a security-patch dependency update in **go-swagger**, and an **analysis** `v1.0.1` bump
pulled through the toolchain. Around that ran a short run of correctness fixes — a
recursion guard in **validate**, a duration-overflow fix in **strfmt**, and a spec-diff fix
in **analysis** — plus a generator speed-up and a new CLI flag in **go-swagger**, the
busiest repository of the month.

## Themes

- **Dependency and security maintenance.** `golang.org/x/net` was updated in **runtime**
  (#553) and **validate** (#307, alongside a `strfmt` bump), **go-swagger** took a
  security-patch dependency update (#3519), and **go-swagger** moved to **analysis**
  `v1.0.1` (#3513). Dependabot carried the bulk of the routine bumps across the fleet.
- **Correctness fixes.** **validate** added a recursion guard so a pooled validator is not
  redeemed twice when `Validate` panics — for example on a `$ref` under a property that
  cannot be expanded — which previously double-freed the child slot (#306). **strfmt**'s
  `ParseDuration` now rejects a duration sum that overflows `uint64` instead of wrapping to
  `0` and passing the range check (#312). **analysis** fixed its spec diff to compare
  `MaxLength`, not `MinLength`, in `CheckStringTypeChanges` (#253).
- **go-swagger generator and CLI.** The generator now analyzes the spec once per generation
  run rather than repeatedly (#3517), and a new command-line argument configures the assets
  URL (#3518). Released as `v0.36.7`.
- **Doc UI.** **runtime** loads Redoc v3 as an ES module — the "latest" CDN bundle is now an
  ES module and failed with `Cannot use 'import.meta' outside a module` under a classic
  `<script src>` — pinning the default to `redoc@3` and keeping the v2 bundle behind
  `WithRedocV2` (#552).
- **go1.27 forward-compatibility.** **codescan** fixed a test that failed under go1.27
  (#167).
